# Campus
Дошка оголошень для учасників навчального процесу.  Полегшує процес знаходження і покупки вживаних товарів, та полегшує процес продати товар. Мета проєкта: створити вебзастосунок де можна купити, продати або обміняти товар, і покупець та продавець можуть легко знайти один одного. Студентська спільнота і викладачі.
